## 4. 红点定性：DEV3 mesh pairing 401（非对齐回归）

- 现象：`superd-hub exec` 与 `remote`（hub lane）打 `hub:bfwu`（DEV3）均得 401；roster 中 bfwu agents 为空。
- 佐证：`remote` oneshot `ssh:dev3` 探针 —— DEV3 当前仅运行 `dsh.service`、4998 测试线（`.tests/dsh-0.2.2-alpha.2-install`）、14997/14998 两枚 registry-pair 与 socat relay，**无任何 superd hub/agent peer 进程**。
- 定性：**stale pairing + 对端下线**的环境态。鉴权失败面在两个工具上均干净、可诊断、可恢复（对端回线后 reprobe/re-pair 即可），无数据损坏、无崩溃。
- 遗留动作：DEV3 的 superd hub 重新在役后做一次 reprobe + `hub:bfwu` exec 复验；届时再验 hub 二进制车道（SHA-256 verify）在该对端的形态。
