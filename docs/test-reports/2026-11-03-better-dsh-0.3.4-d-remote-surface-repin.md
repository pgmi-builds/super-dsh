# better-dsh 0.3.4-d — remote 工具 surface 重钉（对齐原生 dsh 文案）

**日期** 2026-11-03 · **发布** better-dsh only（super-dsh 仅版本同步，不发包）· **性质** 模型侧 surface 变更，零行为改动

## 1. 变更内容

`REMOTE_TOOL_DESCRIPTION`（`better-dsh/src/remote/tool.ts`，唯一源码改动）从 0.3.3-b 钉扎面整体替换为 user 提供的原生 dsh remote 工具文案，**逐字节采纳**（2026-11-03 user 指令："use the exact content"）：

- 头行改为能力概括式：`Default PTY, stateful one-shot, persistent cwd/env, interactive stdin, managed bounded terminal output, exact exit/cwd/env-delta receipts, both stdout/stderr in output`。
- Examples 区扩为教学式：PTY 首选场景带真实回执行（`[pty:… · cwd … · env +STAGE · idle-left ~15m · exit 0 …]`、exit 23 的 stderr 混排示例）、oneshot 隔离语义注记；`remote_transfer` 仍独立收尾。
- Actions / Targets & Semantics 各行**未动**（与 0.3.3-b 面逐字相同）。
- 原生面自带的**重复 `Examples:` 标题行按原样保留**——已核实为本会话原生 dsh 工具目录同款特征，非转写残留；钉扎测试将其作为原文特征钉入，防止后续被"顺手修复"。

## 2. 为什么逐字节搬运而非手抄

模板字面量内含约 30 个反引号、`\n` / `\u0003` 双字符可见序列（误写会变成真换行）与 `\\n` JSON 转义层（示例行内是两个反引号字符）。流程：会话缓存取原文 → 程序化转义拼接 → Node 渲染回读比对，**渲染结果 3341 字符与原文完全一致**（源码与构建产物两侧各验一次）。
