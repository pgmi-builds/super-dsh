# 0.3.1-a Registry release and production deployment

Date: 2026-10-12. Status: published and deployed to PC and DEV3 Production.

The user explicitly authorized “Push and Publish 031A 版本。然后你再从 Registry 安装到这个 PC 和 DEV3 的 Production，重启这两个 DSH 服务”. Both independent npm packages, `better-dsh@0.3.1-a` and `super-dsh@0.3.1-a`, were published once each with the `latest` dist-tag. Their release source was pushed to `origin/master` as `fd07602`. Both production `web` profiles installed the exact pair from the public Registry through the native DSH plugin CLI; their `dsh.service` units were restarted once each and are active.

This release carries the Python environment correction described in [the correction report](2026-10-12-python-environment-discovery.md): the OMP-backed pad selects the existing `python3` or `python` on `PATH`, uses its bundled runner and dill, and does not provision a pinned Python 3.11 or a kernel venv in `node_modules`. The build uses the reviewed runtime code from the accepted 0.3.1-c iteration with final 0.3.1-a version metadata.
