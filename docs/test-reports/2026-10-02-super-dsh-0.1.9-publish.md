## 2. What is in it

Everything accumulated since the published `0.1.6`:

- **0.1.7 / 0.1.7-a…m** — post-office machine mesh consolidated: envelope protocol v1, dual-sided registry,
  exactly-once ingest, self-description discipline, mutual pairing; spec D16–D22.
- **0.1.8 / 0.1.8-a…e — the surface pass** (user-decided, D24–D30): `new_conversation` retired into `send`
  (single door, `conversationId` is the only create/continue discriminator, `message` always required,
  `agent` required only to open); receipt vocabulary `delivered` / `accepted` / `failed` with the 10 s sync
  window + 120 s total wire budget and **no polling surface**; `stop` semantics spelled out on the surface
  (`stopped:true` iff a live turn was cancelled; a natural end is idle); D30 `lastOutput` persisted on the
  conversation row under the ownership gate; messaging/status split (status lives on the Hub face).
- **First-person fixes**: F1 legacy `injected` tolerance, F2 self-addressed continuations discriminate by
  session (not address), F3 `lastOutput` on the channel path, F4 one artifact per turn, O1 boot-time
  reprobe, **O1b** boot tick no longer samples the local plane + an all-error collection is a machine
  failure + `agent_status` explains an empty window.
- **DSH 0.2.0-rc.2 alignment**: verified live, 12/12 surfaces, no SuperD row disabled — see
  `2026-10-02-superd-dsh-0.2.0-rc.2-alignment.md`.
