## 二、测试（10 新）
- framing：wrap/parse 回环（exit+cwd；cwd 可含分号）、**错 nonce 永不帧**（流过为输出）、holdback 前缀扣留、flush 裸放出、tailWindow banner。
- session（fake channel）：init 握手→dispatch→帧结算；FIFO + 会话复用（init 恰一次）；传输死亡诚实结算 + 下次 dispatch `reconnected:true`；**超时两段打断**（`\x03` + 注入 130-marker → 帧 130 → timedOut 且会话存活）。
- **真 script 集成**：本地真 PTY 上 `cd /tmp` 后 `pwd` → cwd 持久。
- **执行器端到端**：in-process http+WS 全环（init→dispatch→exit→cwd 跨 wire 持久）。
- 认证门：authorize=false → upgrade 拒绝，会话初始化失败。

## 四、边界与后续
- 控制帧 MVP：连接即 start、退出即 exit 帧；resize/signal 控制帧未实现（spec §8.2 全集留增量——交互终端 UI 出现时才需要）。
- 会话键 = (DSH session, machine)：agent 会话结束不自动清池（idle TTL 600s 兜底）；需要时可挂 session 结束钩子。
- 工具腿模型面：与 oneshot 同因（rig approval policy 需在场批准）——单元 + in-process WS 端到端已覆盖，浏览器亲测留给用户。
