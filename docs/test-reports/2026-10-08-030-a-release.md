## Authorized production removal and preserved history

On dev3, the native `dsh plugin --profile web remove super-dsh better-dsh`
operation removed the accepted h installation and its delivered companion.
Both dependencies and native bundle selections are absent. Other plugins,
sessions and runtime data remain; production DSH stayed active with PID 571902
and was not restarted. The release is not reinstalled into production.

The migration preserves Better HEAD as merge first parent and the old Super
master as second parent. The original Better checkout's 2,038 recorded files,
porcelain status and refs remain unchanged; all 296 old commits are present.
The existing GitHub `master` can fast-forward, with no history rewrite. Legacy
Better public branches/tags use `legacy/better-dsh/`; private stash/checkpoint
refs, local Claude settings and unrelated desktop research are excluded.

Test services remain available at https://test.pc.internal.test/ and via
the existing dev3 review tunnel http://192.0.2.130:4996/.
The final tarball is also served at
https://view.pc.internal.test/super-dsh-0.3.0-a.tgz.
