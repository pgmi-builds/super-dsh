## 0. 结论

1. **30K 返回窗口层整体移除**：client 侧 `tailWindow` ×5（driver hub oneshot / dispatchPty / oneshot / hubOneshot + hub-tool pty）、配置键 `maxOutputChars`（RemoteRowConfig + zod default）、对端 `runOneShotExec` 的 `EXEC_TAIL_WINDOW` —— 全部退役。
2. **留存层保留并成为唯一上界**：native/PTY ring 4,000,000 UTF-16 单位、hub oneshot 4MiB bytes；驱逐（>4M）时返回 retained 尾 + 一行 `[retention tail: …]` banner + `outputStats`，`truncated` = 原始总量（remote 工具）/boolean（hub 对端 wire 形状不变，混版对端安全）。
3. **新 helper `disclose(text, stats?)`**（nonce-framing.ts，闭包导出替代 tailWindow）：无驱逐全量透传（returned=retained，无 banner）；驱逐才 banner。
4. **surface 同步**：remote 工具 PTY 段改「Output returns in full up to retention …redirect bulk output to files」；hub-tool 三处 30k 措辞与 schema 两处描述改留存口径；docs/remote-tools.md 同步（含 better-dsh/docs 副本随构建）。
5. 测试账：better-dsh remote **246 pass / 8 skip / 0 fail**（254 tests；截断钉改写为全量钉 + disclose 双钉 + config 形状钉×2 + legacy-peer 钉改写）；superd-hub **647 pass / 1 skip / 0 fail**（含 runOneShotExec 全量/驱逐/emoji 边界三钉改写）。
6. **过程纠错（如实记录）**：一次后台套件跑因 `cd` 失败 + `| tail` 吞退出码呈现假绿——终跑抓出 4 个残留断言（config 形状 ×2、旧窗口行为 ×2）并修复；连带发现 renderValue 的「returned tail only」措辞不再恒真（stats 不可用 ≠ 一定是尾），改为中性披露。修复已重建重打包并双 rig 重装（同版本重装需先 remove 再 add——pnpm 对同版本 no-op，本次实测教训）。终版发运对：pack stdout `10b0c629…` / `c0c3c42d…`（以盘上文件 + pair.json 为准）；双 rig 安装态 `plugin.js` = `f643109a2bd4a045…` 与终版 tarball 一致。

## 3. 已知形状披露

- `>4M` 输出的驱逐 banner 从 `[truncated: showing last N of M chars]` 变为 `[retention tail: showing last N of M chars; dropped head D, retention limit L …]`——只在留存驱逐时出现；正常量级（≤4M）无任何前缀。
- hub 对端 `OneShotExecResult.truncated` 保持 boolean（wire 形状冻结，混版对端安全）；remote 工具侧 `truncated` 仍是数字（原始总量），仅在驱逐时出现。
- `maxOutputChars` 配置键从 RemoteRowConfig 退役（配置的就是这层窗口）；zod strict 下旧配置残留该键会报错——如实行为，升级指引即删除该键。
- DSH 原生 spill-policy 阈值（约 50K 字符）不是我们的契约：任何 runtime 自行决定 inline/spill；工具只保证全量交付到 runtime 边界。

## 4. 披露补充与清理

- **hub-tool（A2A `exec`）未另开 live 会话重驱**：其 oneshot 路径即对端 `runOneShotExec`（单测三钉：160000 全量 / 4MiB 驱逐 / emoji 边界 32004 全量），其 pty 路径与 remote 工具共用 `disclose`（同一闭包）——行为同源，如实披露未逐条 live 复测。
- 模型观察到 ssh oneshot 回执 `runner: superd-run 0.3.1-d.b596`——helper 二进制有独立版本节奏，未随包版本刷新；这是既有形状（runner 字段如实披露实际缓存），非本轮回归。
- 会话 PTY 全部 close（回执 `closed:true` ×2），roster `pty sessions: none`。
- 验收脚本与产物：`.scratch/v032e-acceptance.mjs`、`/tmp/v032e-acc.jsonl`（保留供查证，可删）。
